# Thuc Don Dinh Duong

Website HTML/CSS/JavaScript thuan, co the chay tren GitHub Pages.

## Chay tren GitHub Pages

1. Tao repository moi tren GitHub.
2. Tai len toan bo file trong thu muc nay, trong do `index.html` nam o thu muc goc.
3. Vao `Settings` -> `Pages`.
4. Chon `Deploy from a branch`.
5. Chon nhanh `main`, thu muc `/ (root)`, roi bam `Save`.
6. Cho vai phut, GitHub se cap dia chi dang `https://ten-tai-khoan.github.io/ten-repository/`.

## Su dung

- Chi chinh gia theo VND/100g.
- Bam `LEN THUC DON` de tu dong tim khau phan toi uu.
- Trung duoc tinh theo quy uoc 2 qua = 100g.
- So luong chua tinh hien thi 0.
